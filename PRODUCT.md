# Product Context

register: product

## Product Purpose

Edge AI Parking System helps parking operators monitor vehicle detection, license plate recognition, slot occupancy, and safety events from an edge AI pipeline.

## Users

- Parking attendants watching a live dashboard during daily operations.
- Site administrators checking vehicle and slot records.
- Engineers validating YOLO/OCR model integration before deployment.

## Tone

Calm, operational, precise. The interface should feel like a control surface for repeated use, not a marketing page.

## Strategic Principles

- Make live state scannable before details.
- Keep warnings visible without making normal operation feel alarming.
- Preserve mock mode usefulness while real YOLO/OCR integration matures.
- Favor dense, predictable product UI over decorative composition.

## Anti-References

- Oversized SaaS hero dashboards.
- Decorative glass panels and gradients.
- Toy-like smart parking mockups that hide real operational state.
