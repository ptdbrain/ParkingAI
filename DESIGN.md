# Design Context

## Register

Product dashboard.

## Color Strategy

Restrained, with tinted neutrals and semantic state colors. Use OKLCH tokens. Green is reserved for healthy/occupied/connected states, amber for review, red for safety or connection problems, blue for informational OCR/model events.

## Typography

Use the native system sans stack. Keep labels compact, numeric values tabular, and headings modest.

## Components

- 8px radius or less.
- Dense tables and event feeds are acceptable.
- No nested cards.
- Use skeleton or quiet empty states instead of centered spinners.

## Motion

Short state transitions only, 150 to 220 ms, ease-out. No decorative page-load choreography.
